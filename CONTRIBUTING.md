# Contributing

This project is currently in planning and source research. Start with the [roadmap](docs/ROADMAP.md) and the [pinned upstream baseline](docs/UPSTREAM_RESEARCH.md).

Write documentation, issue reports, and pull request descriptions in English. Use concrete evidence for compatibility claims. Distinguish intended behavior, source observations, and behavior reproduced in the game.

Keep changes focused on the classic wild encounter mode. Record the exact game build and upstream revision when investigating hooks. When implementation begins, include relevant calculation/state tests and gameplay evidence for changes to the encounter loop.

Do not commit game dumps, encryption keys, saves, extracted assets, generated game code, local runtime packages, or personal configuration. Link to third-party work and respect its terms. Retain attribution and license notices when importing permitted source code.

For a pull request, explain the problem, the resulting behavior, verification performed, and remaining limitations. Clearly mark checks that were not run.
